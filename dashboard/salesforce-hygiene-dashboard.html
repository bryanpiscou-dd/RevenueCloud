Salesforce hygiene dashboard

Where ownership, pipeline, users, contacts and automation have drifted. Each check shows the count, the base it is measured against, and the records to fix.

What this dashboard cannot tell you yet

  • Flow last run date. Salesforce does not expose it in queryable data. The flow check uses last modified date as a proxy. A flow edited 14 months ago may still run daily. To get real run history, enable Flow Event Monitoring (Shield) or add a log write in each flow.
  • Account country. 98% of accounts have no Billing Country. Before treating it as a defect, confirm which field is the source of truth for territory and region.
  • Sample cap. The flow list is capped at 200 custom active flows, ordered oldest first.

Queries and the native Salesforce report build spec are in dashboard/hygiene-checks.md. Counts are a point-in-time snapshot, refresh by re-running them.
