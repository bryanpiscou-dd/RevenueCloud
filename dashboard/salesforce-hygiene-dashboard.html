Salesforce hygiene dashboard

Where ownership, pipeline, users, contacts and automation have drifted. Each check shows the count, the base it is measured against, and the records to fix.

What this dashboard cannot tell you yet

  • Flow last run date. Salesforce does not expose it in queryable data. The flow check uses last modified date as a proxy. A flow edited 14 months ago may still run daily. For real run history, enable Flow Event Monitoring (Shield) or add a log write in each flow.
  • Territory rules. New US Territory also carries EMEA and Latin America. Japan, India, China and Australia are almost all EMEA (7,606 of 7,633 for Japan), so I treated EMEA as the rest-of-world default and did not flag it. Confirm that is the intended design.

Queries and the native Salesforce report build spec are in dashboard/hygiene-checks.md. Counts are a point-in-time snapshot, refresh by re-running them.
